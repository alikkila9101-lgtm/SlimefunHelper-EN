# SlimefunHelper — English localization

Unofficial **English translation** of [SlimefunHelper](https://github.com/m1919810/SlimefunHelper) by m1919810 — a Fabric **client-side** mod with quality-of-life features for playing on Slimefun servers, built for **Minecraft 1.21.11**.

> This branch (`english-translation`) translates all user-facing strings: 2903 lang-file entries (GUI labels, settings, tooltips) and 629 hardcoded strings in Java. The upstream base is untouched on the `1.21.11` branch. Original Chinese README: [README-ZH.md](./README-ZH.md).

## Features

- Client-side Slimefun guide book and recipe database
- Multiblock build assistant
- Client-side textures for Slimefun items
- Container item info, NBT/item editor, item library
- Inventory QoL (sorting, quick move, chest GUI manager)
- Entity/block trackers, HUD widgets, Xaero's Map support

## Install

1. [Fabric Loader](https://fabricmc.net/use/) 0.18+ for Minecraft 1.21.11
2. [Fabric API](https://modrinth.com/mod/fabric-api)
3. Drop the jar from [Releases](../../releases) into your `mods` folder

## ⚠️ Fair-play warning

Besides QoL, the mod ships optional automation modules (auto-mine, aimbot, flight, NoFall) — some explicitly built to bypass **GrimAC**. On servers with anticheat (GrimAC, Vulcan, Matrix…) using those modules will get you banned. Keep combat/moving/mining modules disabled and follow your server's rules. Everything here is provided as-is, use at your own risk.
